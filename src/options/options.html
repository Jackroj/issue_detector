AI Assistant

Off by default. When enabled, the "Analyze with AI" button on a finding sends only structured data to the provider below: the finding's title/description/evidence (already shown in this UI), nearby timeline entries, and related finding titles. It never sends request/response bodies, cookies, or page source — those are never collected in the first place. Anything that looks like a token, JWT, or email address in a URL is redacted before sending, even to a local provider.

Requires Ollama running locally with a model pulled (e.g. ollama pull llama3.2). If the check below fails with a connection error, start Ollama with OLLAMA_ORIGINS=chrome-extension://* set so it accepts requests from this extension.
